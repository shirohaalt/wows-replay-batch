# WoWS 队伍回放助手使用说明

按队伍名称查询比赛、批量下载 REP 回放，并转换为 MP4 小地图战术视频。下载与转换分别操作，可按需选择比赛、回放视角、双方 BP 信息和舰船轨迹。

## 启动程序

1. 解压完整压缩包，保留程序旁的 `tools`、`cache` 等文件夹。
2. 双击 `WoWSReplayBatch.exe`。Windows 发布包无需另装 Python 或 FFmpeg。
3. 首次启动默认选择亚服；队名、REP 保存位置、转换清单和本地回放文件夹由使用者自行填写或选择。

## 下载 REP

1. 进入「01 下载 REP」，在「赛事服务器」下拉框选择亚服、欧服或美服，程序会自动切换到对应赛事网址。
2. 输入队伍名称或队标，点击「查询比赛」。支持部分关键词，忽略大小写；匹配到多支队伍时，在队名右侧下拉框中选择目标队伍。
3. 点击「选择文件夹」，设置 REP 保存位置。
4. 如需双方回放，勾选「同时下载对手视角」。未勾选时，只下载目标队伍提交的回放。
5. 选择下载范围：
   - 「全部下载」：下载当前选定队伍的全部查询结果，不受比赛勾选状态影响。
   - 「下载已勾选比赛」：只下载打勾的比赛。可逐场勾选，或使用「全选比赛」「清空勾选」。
6. 下载时查看整批及单文件进度条；展开比赛行可查看各局 REP 的视角和状态。

下载结束后不会自动转换。修改队名或服务器后，需要重新查询。网站尚未提供的回放会记录为缺失项，可稍后再次尝试。

## 转换视频

1. 进入「02 转换视频」。刚下载的回放会自动载入；也可点击「选择清单」，选择已有的 `manifest.json`，或输入清单所在目录后点击「读取」。
2. 选择全部、目标队伍或对手视角，按比赛、地图、队伍关键词筛选，并勾选需要转换的回放。
3. 设置视频内容：
   - 「视频显示双方 BP 信息」：在小地图下方显示双方提交的禁船信息。
   - 「全部舰船」：显示所有舰船轨迹。
   - 「仅指定舰船」：只显示自行勾选的舰船轨迹。
   - 「关闭轨迹」：不绘制舰船轨迹。
4. 点击「转换已勾选回放」。筛选生效时，只处理当前列表中已勾选的回放。
5. 转换结束后，双击任务播放视频，或点击「打开结果目录」查看文件。

转换使用本地 REP，不会重新下载回放。首次处理某个游戏版本时，可能需要自动下载对应的公共游戏素材。

## 转换自行保存的本地回放

1. 进入「03 本地回放转换」，点击「选择文件夹」，选择存放 `.wowsreplay` 文件的位置。
2. 点击「读取回放」。程序会扫描该文件夹及其子文件夹，显示回放文件、地图、玩家、舰船、游戏版本和对局时间，无需赛事下载清单。
3. 勾选需要转换的回放。可按文件、地图、玩家或舰船筛选，也可全选、清空当前列表。
4. 选择全部舰船轨迹、仅指定舰船或关闭轨迹；指定舰船的操作与下一节相同。
5. 点击「转换已勾选回放」。转换完成后双击任务播放视频，或点击「打开结果目录」。

本地转换不显示 BP 选项，视频也不添加 BP 信息。原始回放保持不变；视频和转换记录保存到所选文件夹的 `WoWSReplayBatch-output` 子目录，其中视频位于 `videos/`。

不能读取的文件会跳过并记录原因。更改文件夹或修改回放后，请重新「读取回放」。再次读取相同回放会保留转换记录；首次使用对应游戏版本时仍可能下载公共游戏素材。

## 选择指定舰船轨迹

1. 在转换页读取回放清单，点击「选择舰船…」。
2. 在左侧选择具体比赛和回放视角，在右侧勾选需要显示轨迹的玩家、舰船。同型舰可以分别选择。
3. 保存选择，使用「仅指定舰船」模式转换视频。

每份回放分别保存舰船选择。**指定舰船模式下，未指定舰船的回放不显示轨迹。** 其他舰船图标仍会保留。

轨迹依据回放中实际记录的位置绘制；不可见或缺少记录的区间会断开。单方回放的内容受战争迷雾影响。

## 查询 BAN/PICK

1. 在下载页查询并选定目标队伍，点击「BAN / PICK 查询」。
2. 在左侧选择比赛，切换右侧标签，查看双方禁船、地图 BAN/PICK、每局实际阵容和队伍统计。
3. 可按对手、舰船、地图或玩家筛选，使用「导出 JSON」「导出 CSV」保存查询结果。
4. 数据不完整时点击「刷新队伍数据」，也可通过「打开原站记录」查看比赛页面。

实际阵容来自双方比赛报告。网站未公开逐步选船过程时，只展示出场名单；赛事指定的地图会单独标明。视频中的 BP 信息栏展示双方提交的禁船。

## 文件保存与继续处理

下载结果按赛事、赛区、队伍分类保存在自行选择的位置：

- `replays/`：原始 REP 回放。
- `videos/`：转换后的 MP4 视频。
- `manifest.json`：回放清单，继续转换时读取此文件。
- `ban-pick.json`：已查询的 BAN/PICK 数据。
- `logs/`、`run.log`：处理日志，排查失败原因时查看。

点击「停止当前任务」后，已完成的文件会保留。再次执行时会复用有效文件；补下载部分比赛不会移除其他已下载回放。修改 BP 或轨迹选项后，可重新转换选中的回放。

## 检查和下载更新

1. 点击主界面右上角「检查更新」，确认 GitHub 仓库地址。
2. 点击窗口中的「检查更新」，查看最新正式版本和更新说明。
3. 发现新版本后点击「下载更新」，程序会自动下载，并显示已接收容量及进度。需要中止时点击「取消」。
4. 下载和 SHA-256 校验完成后，点击「打开下载位置」，找到 `updates` 文件夹内的 ZIP 更新包。
5. 结束正在运行的任务、退出程序，将更新包解压到新文件夹后启动新版。在转换页读取原来的回放清单可继续处理。

更新窗口可与 REP 下载、视频转换同时使用。当前版本只下载更新包，不会自动执行、覆盖程序或上传本地设置与回放。没有新版本时会显示当前已是最新版本；检查失败时可在「设置」中配置代理后重试。

## 设置与常见问题

- **网络不稳定**：在「设置」中填写可用的 HTTP 代理；不使用代理时留空。
- **需要本地游戏素材**：可在「设置」中选择与回放版本对应的游戏目录，程序只读取该目录。
- **找不到队伍**：确认赛事和赛区，缩短关键词后重试。关键词匹配不会纠正拼写错误。
- **部分回放缺失**：可能尚未开赛、尚未上传或没有公开回放，可查看原站记录。
- **转换失败**：查看任务状态和日志，确认回放版本所需素材可用后重试。
- **视频内容**：输出为 H.264 MP4 小地图战术快放，展示舰船移动、占点等信息；不是游戏客户端的 3D 录像。

个人设置保存在本机 `settings.json` 中。发布压缩包不包含个人设置、使用记录、界面截图、回放或回放相关缓存。

## 源码启动

安装 Python 3.11 或以上版本后，在源码目录运行：

```powershell
python -m pip install -r requirements.txt
python main.py
```
